## English

### Short description (80 chars max)

```
Practice CNC G-code and M-code meanings offline with an adaptive quiz.
```

### Full description (4000 chars max)

```
G-Code Quiz helps you learn and practice CNC G-code and M-code programming fundamentals, entirely offline.

FEATURES

- 60+ quiz questions covering common G-codes and M-codes, organized by category and topic
- Two quiz modes: Code → Meaning (what does this code do) and Action → Code (which code performs this action)
- Choose how questions are ordered: random, weakest first, longest since answered, or least answered
- Adaptive distractors: the wrong answers you tend to pick are more likely to show up again, so you get targeted practice on your actual mistakes
- Questions and answer choices are shuffled each session to keep practice fresh
- Stats screen with your overall accuracy, accuracy by topic, and your weakest questions
- Back up your answer history to a file and restore it later, so your progress travels with you
- English and Russian interface and quiz content, with a language toggle
- No account, no ads, no internet connection required — all your data stays on your device

WHO IT'S FOR

Whether you're a machinist, CNC programming student, or hobbyist getting started with G-code, this app gives you quick, focused practice you can do anywhere, without needing a network connection.
```
